Aula 09 — Seletores CSS

Os seletores definem quais elementos HTML receberão um estilo. Dominar os seletores é fundamental para escrever CSS eficiente e organizado.

1. Seletor de Tag (Tipo)

Seleciona todos os elementos de um determinado tipo HTML.

/* Aplica a TODOS os parágrafos */
p {
    color: purple;
}

/* Aplica a TODOS os h2 */
h2 {
    color: green;
}
Uso: estilizar elementos de forma global no documento.

Parágrafo 1 — seletor de tag aplicado (cor roxa)

Parágrafo 2 — mesmo seletor, mesmo estilo

2. Seletor de Classe (.classe)

Seleciona todos os elementos que possuem um determinado class.

/* No CSS */
.cor-verde {
    color: green;
    font-weight: bold;
}

<!-- No HTML -->
<p class="cor-verde">Verde e negrito</p>
<span class="cor-verde">Também verde!</span>
✅ Reutilizável: a mesma classe pode ser aplicada em vários elementos.
✅ Um elemento pode ter múltiplas classes: class="cor-verde destaque"

Este parágrafo tem class="cor-verde"

Este span também tem class="cor-verde"

3. Seletor de ID (#id)

Seleciona o elemento que possui um determinado id. O ID deve ser único na página.

/* No CSS */
#unico {
    background: yellow;
    border: 2px solid orange;
}

<!-- No HTML -->
<p id="unico">Elemento único</p>
⚠️ Use IDs para identificar elementos únicos (cabeçalho, rodapé, menu). Para estilização reutilizável, prefira classes.

Este parágrafo tem id="unico" — fundo amarelo e borda laranja

4. Seletor Universal (*)

Seleciona todos os elementos do documento (ou de um contexto).

/* Aplica a tudo */
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

/* Aplica a tudo dentro de .container */
.container * {
    border: 1px dashed blue;
}

5. Seletores de Combinação

5.1 Descendente (espaço)

Seleciona elementos dentro de outro, em qualquer nível.

.container p { color: red; }  /* qualquer <p> dentro de .container */

Parágrafo direto — cor vermelha

Parágrafo aninhado — também vermelho (é descendente)

5.2 Filho Direto (>)

Seleciona apenas filhos diretos, não os aninhados.

.container > p { color: blue; }  /* apenas <p> filhos diretos */

Filho direto — azul e negrito ✅

Neto (não filho direto) — NÃO recebe o estilo ❌

6. Seletor de Atributo

Seleciona elementos com base em seus atributos HTML.

input[type="text"]  { border: 2px solid green; }
input[type="email"] { border: 2px solid red; }
a[href]             { color: purple; }          /* qualquer link com href */
a[href^="https"]    { color: green; }           /* links que começam com https */

  

7. Pseudo-classes (:)

Selecionam elementos em um estado específico.

a:hover      { color: red; }          /* mouse sobre o link */
li:first-child { font-weight: bold; } /* primeiro item da lista */
li:last-child  { color: gray; }       /* último item */
li:nth-child(2){ color: blue; }       /* segundo item */
input:focus    { outline: 2px solid blue; } /* input em foco */
Passe o mouse sobre os itens da lista abaixo:
  • Primeiro item (negrito verde)
  • Segundo item
  • Terceiro item
  • Quarto item (itálico cinza)

8. Pseudo-elementos (::)

Estilizam partes de um elemento.

p::first-letter { font-size: 2em; color: red; }  /* primeira letra */
p::first-line   { font-weight: bold; }            /* primeira linha */
p::before       { content: "▶ "; color: blue; }  /* conteúdo antes */
p::after        { content: " ✓"; color: green; } /* conteúdo depois */

Parágrafo com pseudo-elementos: a primeira letra é grande e vermelha, e antes do texto há uma seta azul.

9. Agrupamento de Seletores

Aplique o mesmo estilo a vários seletores separando-os por vírgula.

/* Sem agrupamento */
h1 { color: purple; }
h2 { color: purple; }
h3 { color: purple; }

/* Com agrupamento */
h1, h2, h3 { color: purple; }

h3 com agrupamento — cor roxa

h4 com agrupamento — cor roxa
