Aula 12 — Transições e Animações

CSS permite criar movimento e feedback visual sem JavaScript, usando transition para efeitos simples e animation + @keyframes para sequências complexas.

1. transition

Suaviza a mudança de um estado CSS para outro (ex: normal → hover).

/* sintaxe completa */
transition: propriedade  duração  timing-function  delay;

/* exemplos */
transition: all 0.3s ease;
transition: background-color 0.5s ease-in-out;
transition: transform 0.4s cubic-bezier(.68,-0.55,.27,1.55);

/* múltiplas propriedades */
transition: background 0.3s ease, transform 0.4s ease;

2. @keyframes — definindo a animação

@keyframes nome-da-animacao {
    0%   { propriedade: valor-inicial; }
    50%  { propriedade: valor-meio; }
    100% { propriedade: valor-final; }
}

/* atalho */
@keyframes aparecer {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
}

3. animation — aplicando a animação

/* sintaxe */
animation: nome  duração  timing  delay  iterações  direção  fill-mode;

/* exemplos */
animation: pulsar 1.5s ease-in-out infinite;
animation: aparecer 0.6s ease forwards;         /* forwards = mantém estado final */
animation: girar 1s linear infinite;
animation: piscar 0.5s ease-in-out 3 alternate; /* 3 vezes, vai e volta */
PropriedadeValores comuns
animation-iteration-count1, 3, infinite
animation-directionnormal, reverse, alternate
animation-fill-modenone, forwards, backwards, both
animation-play-staterunning, paused

4. transform

Usado em conjunto com transitions e animations para mover, girar, escalar e distorcer elementos.

transform: translateX(50px);           /* move no eixo X */
transform: translateY(-20px);          /* move no eixo Y */
transform: translate(30px, -10px);     /* move em X e Y */
transform: scale(1.5);                 /* aumenta 50% */
transform: scale(0.8);                 /* diminui 20% */
transform: rotate(45deg);             /* gira 45 graus */
transform: skewX(20deg);              /* distorce no eixo X */

/* combinados */
transform: translateY(-8px) scale(1.05);

translateY

scale

rotate

skewX

💡 Performance: prefira animar transform e opacity — o navegador as processa na GPU sem recalcular o layout. Evite animar width, height, top ou left em loops.
