Aula 10 — Responsividade

Um site responsivo adapta seu layout a qualquer tamanho de tela: celular, tablet ou desktop. A base é a viewport meta tag e as media queries.

1. Viewport meta tag — obrigatória!

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Essa tag diz ao navegador móvel para usar a largura real da tela em vez de simular um desktop. Sem ela, nada funciona no celular.

2. Media Queries

Permitem aplicar estilos diferentes dependendo do tamanho da tela.

/* estilos base — mobile first */
.container { padding: 16px; }

/* tablet: 768px ou mais */
@media (min-width: 768px) {
    .container { padding: 24px; }
}

/* desktop: 1024px ou mais */
@media (min-width: 1024px) {
    .container { padding: 40px; max-width: 1200px; margin: 0 auto; }
}
Mobile First: comece pelos estilos do celular e vá adicionando com min-width. É a abordagem recomendada.

Sintaxe das media queries

@media (min-width: 768px) { ... }   /* largura mínima — a partir de */
@media (max-width: 767px) { ... }   /* largura máxima — até */
@media (min-width: 480px) and (max-width: 767px) { ... } /* intervalo */
@media (orientation: landscape) { ... } /* paisagem */
@media print { ... }  /* impressão */

4. Layout responsivo com Flexbox

/* mobile: empilhado */
.cards { display: flex; flex-direction: column; gap: 16px; }

/* tablet: 2 colunas */
@media (min-width: 768px) {
    .cards { flex-direction: row; flex-wrap: wrap; }
    .cards .card { flex: 1 1 calc(50% - 8px); }
}

/* desktop: 3 colunas */
@media (min-width: 1024px) {
    .cards .card { flex: 1 1 calc(33.333% - 11px); }
}

5. Layout responsivo com Grid

/* sem media query — grid automático */
.galeria {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 20px;
}

/* com media query para controle fino */
.grid {
    display: grid;
    grid-template-columns: 1fr;  /* 1 coluna no mobile */
}
@media (min-width: 768px) {
    .grid { grid-template-columns: 1fr 1fr; }  /* 2 colunas */
}
@media (min-width: 1024px) {
    .grid { grid-template-columns: 1fr 1fr 1fr; } /* 3 colunas */
}

6. Unidades responsivas

UnidadeSignificadoUso típico
%Porcentagem do paiLarguras de container
vw% da largura da viewportSeções full-width
vh% da altura da viewportHero full-height
remRelativo ao root (16px)Fonte, espaçamentos
emRelativo ao paiPadding interno
clamp()Entre mínimo e máximoFonte fluida
/* fonte fluida sem media query */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
/* mínimo 1.5rem, cresce com a tela, máximo 3rem */

/* largura que nunca ultrapassa 1200px */
.container { width: 100%; max-width: 1200px; margin: 0 auto; }

7. Imagens responsivas

/* regra global — nunca ultrapassa o container */
img { max-width: 100%; height: auto; }

/* imagem que cobre o container */
.capa {
    width: 100%;
    height: 300px;
    object-fit: cover;      /* recorta mantendo proporção */
    object-position: center;
}

8. Navbar responsiva — exemplo

/* mobile: menu oculto */
.nav-menu { display: none; flex-direction: column; }
.nav-toggle { display: block; }  /* ícone hambúrguer */

/* desktop: menu visível em linha */
@media (min-width: 768px) {
    .nav-menu   { display: flex; flex-direction: row; }
    .nav-toggle { display: none; }
}
💡 Em projetos reais, o toggle do menu mobile é controlado por JavaScript — mas a base do layout é sempre CSS.
