Aula 13 — Variáveis CSS (Custom Properties)

Variáveis CSS permitem armazenar valores reutilizáveis — cores, tamanhos, sombras — e alterá-los em um só lugar, facilitando a manutenção e criação de temas.

1. Declarando variáveis com :root

:root é o elemento raiz do documento. Variáveis declaradas ali ficam disponíveis em qualquer lugar do CSS.

:root {
    --cor-primaria:   #1abc9c;
    --cor-texto:      #2c3e50;
    --espacamento:    16px;
    --borda-raio:     6px;
    --sombra:         0 2px 8px rgba(0,0,0,.12);
}
O nome de uma variável CSS sempre começa com -- (dois hífens). É case-sensitive: --Cor e --cor são variáveis diferentes.

2. Usando variáveis com var()

/* var(nome-da-variável, valor-padrão-opcional) */
h1    { color: var(--cor-primaria); }
p     { color: var(--cor-texto); }
.card { padding: var(--espacamento); border-radius: var(--borda-raio); }

/* com fallback (padrão caso a variável não exista) */
color: var(--cor-acento, #3498db);

3. Escopo — variáveis locais

Uma variável pode ser redefinida dentro de um seletor. Isso cria um escopo local que só afeta aquele elemento e seus filhos.

/* global — vale em todo o documento */
:root { --cor-primaria: #1abc9c; }

/* local — só o .destaque e seus filhos usam #e74c3c */
.destaque { --cor-primaria: #e74c3c; }

.card { border-top: 4px solid var(--cor-primaria); }
/* resultado: .card normal = verde | .destaque .card = vermelho */

4. Criando temas com variáveis

/* tema claro (padrão) */
:root {
    --cor-fundo: #ffffff;
    --cor-texto: #333333;
    --cor-primaria: #1abc9c;
}

/* tema escuro — redefine as mesmas variáveis */
[data-tema="escuro"] {
    --cor-fundo: #1a1a2e;
    --cor-texto: #ecf0f1;
    --cor-primaria: #1abc9c;
}

body {
    background: var(--cor-fundo);
    color: var(--cor-texto);
}
/* todos os elementos que usam var() se adaptam automaticamente */

5. Usando variáveis com calc()

:root {
    --espacamento-base: 16px;
}

.container { padding: var(--espacamento-base); }
.grande    { padding: calc(var(--espacamento-base) * 2); }  /* 32px */
.pequeno   { padding: calc(var(--espacamento-base) / 2); }  /* 8px */
Variáveis CSS funcionam com calc(), clamp(), min() e max() — ótimo para sistemas de espaçamento proporcionais.
