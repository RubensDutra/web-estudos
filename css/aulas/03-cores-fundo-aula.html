Aula 03 — Cores e Fundo

1. Propriedades de Cor

As duas propriedades principais de cor em CSS são:

color: red;                  /* cor do TEXTO */
background-color: #f0f0f0;  /* cor do FUNDO do elemento */

2. Formas de Declarar Cores

2.1 Nome da Cor (Keywords)

CSS reconhece 140+ nomes de cores em inglês.

color: red;
color: blue;
color: tomato;
color: steelblue;
color: coral;

2.2 Hexadecimal (#RRGGBB)

Formato mais usado. Cada par representa vermelho, verde e azul (00–FF).

color: #ff0000;   /* vermelho puro */
color: #00ff00;   /* verde puro */
color: #0000ff;   /* azul puro */
color: #2c3e50;   /* azul escuro */
color: #ffffff;   /* branco */
color: #000000;   /* preto */

/* Forma curta (quando pares repetem) */
color: #f00;   /* equivale a #ff0000 */
color: #fff;   /* equivale a #ffffff */

2.3 RGB

Valores de 0 a 255 para vermelho, verde e azul.

color: rgb(255, 0, 0);       /* vermelho */
color: rgb(44, 62, 80);      /* azul escuro */
color: rgb(255, 255, 255);   /* branco */

2.4 RGBA (com transparência)

Igual ao RGB, mas com um quarto valor: alpha (0 = transparente, 1 = opaco).

background-color: rgba(231, 76, 60, 0.3);   /* vermelho 30% opaco */
background-color: rgba(0, 0, 0, 0.5);       /* preto semi-transparente */
alpha 1.0

alpha 0.1

2.5 HSL (Matiz, Saturação, Luminosidade)

color: hsl(0, 100%, 50%);     /* vermelho */
color: hsl(120, 100%, 50%);   /* verde */
color: hsl(240, 100%, 50%);   /* azul */
color: hsl(0, 0%, 50%);       /* cinza */
Dica: HSL é intuitivo para criar variações de uma cor — mude só a luminosidade para versões mais claras ou escuras.

3. Propriedades de Fundo

3.1 background-color

background-color: #3498db;
Fundo com background-color: #3498db

3.2 background-image

Define uma imagem de fundo. Pode ser uma URL ou um gradiente.

background-image: url("imagem.jpg");

/* Gradiente linear */
background-image: linear-gradient(to right, #e74c3c, #3498db);

/* Gradiente diagonal */
background-image: linear-gradient(135deg, #2c3e50, #3498db);
Gradiente: linear-gradient(to right, #e74c3c, #3498db)
Gradiente diagonal: 135deg, #2c3e50 → #f39c12

3.3 background-repeat

background-repeat: repeat;     /* padrão: repete em x e y */
background-repeat: no-repeat;  /* sem repetição */
background-repeat: repeat-x;   /* repete só horizontalmente */
background-repeat: repeat-y;   /* repete só verticalmente */

3.4 background-size

background-size: auto;      /* tamanho original */
background-size: cover;     /* cobre todo o elemento (pode cortar) */
background-size: contain;   /* cabe inteiro sem cortar */
background-size: 200px 100px;

3.5 background-position

background-position: center center;
background-position: top right;
background-position: 50% 50%;

3.6 Shorthand background

Todas as propriedades em uma linha só:

background: #2c3e50 url("foto.jpg") no-repeat center center / cover;
/*          cor      imagem         repetição  posição        tamanho */

4. Opacity

Controla a transparência do elemento inteiro (incluindo texto e filhos).

opacity: 1;    /* completamente visível (padrão) */
opacity: 0.5;  /* 50% transparente */
opacity: 0;    /* invisível */
opacity: 1
opacity: 0.6
opacity: 0.3
Diferença: opacity afeta o elemento todo (inclusive texto). rgba() afeta só o fundo, deixando o texto opaco.
