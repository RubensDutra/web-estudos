Aula 08 — Introdução ao CSS

1. O que é CSS?

CSS (Cascading Style Sheets) é a linguagem usada para estilizar documentos HTML: cores, fontes, tamanhos, espaçamentos e layout.

Regra básica: HTML define a estrutura; CSS define a aparência.

2. Sintaxe

Uma regra CSS é composta por seletor, propriedade e valor:

seletor {
    propriedade: valor;
}

/* Exemplo */
h1 {
    color: blue;
    font-size: 32px;
}
  • seletor — qual elemento será estilizado (ex: h1, .classe, #id)
  • propriedade — o que será alterado (ex: color, font-size)
  • valor — o novo valor (ex: blue, 32px)

3. Três formas de usar CSS

3.1 CSS Inline

Aplicado diretamente no atributo style do elemento.

<p style="color: red; font-weight: bold;">Texto vermelho</p>

Demonstração: CSS inline aplicado aqui.

⚠️ Difícil de manter — use apenas em casos específicos.

3.2 CSS Interno

Declarado dentro da tag <style> no <head>.

<style>
    p { color: blue; }
</style>
✅ Centraliza estilos no arquivo. ⚠️ Não se aplica a outros HTMLs.

3.3 CSS Externo

Arquivo .css separado, vinculado com <link>.

<link rel="stylesheet" href="estilos.css">
✅ Melhor prática! Um arquivo CSS estiliza vários HTMLs.

4. Cascata e Especificidade

Quando duas regras conflitam, o navegador usa a especificidade para decidir qual prevalece.

Tipo Exemplo Prioridade
CSS Inline style="color: red" ⭐⭐⭐⭐ (maior)
Seletor de ID #titulo { color: blue; } ⭐⭐⭐
Seletor de Classe .destaque { color: green; } ⭐⭐
Seletor de Tag h1 { color: gray; } ⭐ (menor)

5. Propriedades Essenciais

Cor e Fundo

color: red;                   /* cor do texto */
background-color: #f0f0f0;   /* cor de fundo */

Tipografia

font-family: Arial, sans-serif;
font-size: 16px;
font-weight: bold;
font-style: italic;
text-align: center;
text-decoration: underline;

Espaçamento

margin: 10px;    /* espaço EXTERNO */
padding: 10px;   /* espaço INTERNO */

Borda

border: 1px solid black;
border-radius: 8px;

Resumo

  • CSS estiliza o HTML (cores, fontes, espaçamentos)
  • Sintaxe: seletor { propriedade: valor; }
  • 3 formas: inline, interno (<style>), externo (.css)
  • Cascata: inline > #id > .classe > tag
