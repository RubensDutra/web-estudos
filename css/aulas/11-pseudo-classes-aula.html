Aula 11 — Pseudo-classes CSS

Pseudo-classes selecionam elementos em estados específicos ou baseadas em sua posição na árvore HTML, sem precisar adicionar classes manualmente.

1. :hover — ao passar o mouse

a:hover      { color: red; }
button:hover { background: darkblue; transform: scale(1.05); }
.card:hover  { box-shadow: 0 8px 20px rgba(0,0,0,.2); }
Passe o mouse aqui!

2. :focus — ao focar (teclado / clique)

Essencial para acessibilidade — indica ao usuário qual campo está ativo.

input:focus {
    border-color: purple;
    box-shadow: 0 0 0 3px rgba(128,0,128,.25);
    outline: none; /* remove o padrão e substitui pelo box-shadow */
}

3. :nth-child() — filhos por posição

li:nth-child(odd)  { background: #f5eef8; }  /* ímpares: 1,3,5... */
li:nth-child(even) { background: #e8daef; }  /* pares: 2,4,6... */
li:nth-child(3)    { color: red; }           /* somente o 3º */
li:nth-child(3n)   { font-weight: bold; }    /* a cada 3: 3,6,9... */
li:nth-child(2n+1) { ... }                   /* mesmo que odd */
  • Item 1 (first-child)
  • Item 2 (even)
  • Item 3 (odd)
  • Item 4 (even)
  • Item 5 (last-child + odd)

4. :first-child e :last-child

li:first-child { font-weight: bold; }
li:last-child  { border-bottom: none; }

/* variações úteis */
p:first-child  { margin-top: 0; }
.card:last-child { margin-right: 0; }

5. :not() — negação

Seleciona todos os elementos que não correspondem ao seletor dentro dos parênteses.

button:not(.secundario) { font-weight: bold; }
li:not(:last-child) { border-bottom: 1px solid #ddd; }
input:not([type="submit"]) { border: 2px solid purple; }

6. :checked — caixas e rádios marcados

input[type="checkbox"]:checked + label { font-weight: bold; color: purple; }
input[type="radio"]:checked + label   { color: green; }

7. Outras pseudo-classes úteis

Pseudo-classeSignificado
:visitedLinks já visitados
:activeNo momento do clique
:disabledCampos desabilitados
:requiredCampos obrigatórios
:validCampo com valor válido
:invalidCampo com valor inválido
:emptyElemento sem filhos
:rootElemento raiz (html)
:nth-last-child()Contando do último
Pseudo-classes vs Pseudo-elementos: pseudo-classes selecionam estados (:hover, :focus). Pseudo-elementos criam partes virtuais do DOM (::before, ::after, ::first-line).
