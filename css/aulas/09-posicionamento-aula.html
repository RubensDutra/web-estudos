Aula 09 — Posicionamento

A propriedade position controla como um elemento é posicionado no documento. Os valores top, right, bottom e left só funcionam quando position não é static.

1. position: static (padrão)

O elemento segue o fluxo normal. top/right/bottom/left não têm efeito.

.elemento {
    position: static; /* padrão — nem precisa escrever */
}

2. position: relative

O elemento se move em relação à sua posição original, mas o espaço original é mantido.

.elemento {
    position: relative;
    top: 20px;   /* desce 20px da posição original */
    left: 30px;  /* move 30px para a direita */
}

💡 O espaço que o elemento ocuparia ainda existe — os outros elementos não avançam para o lugar dele.

3. position: absolute

O elemento sai do fluxo e é posicionado em relação ao ancestral mais próximo com position diferente de static.

.pai {
    position: relative; /* cria o contexto de posicionamento */
}
.filho {
    position: absolute;
    top: 10px;
    right: 10px;
}

⚠️ Sem um pai com position: relative, o elemento se posiciona em relação à página inteira (body).

4. position: fixed

O elemento sai do fluxo e fica fixo em relação à janela do navegador — não rola com a página.

.navbar {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    z-index: 100;
}
.botao-topo {
    position: fixed;
    bottom: 20px;
    right: 20px;
}
💡 Use fixed para: navbars que ficam no topo, botões "voltar ao topo", chats flutuantes, cookies banner.

5. position: sticky

Comporta-se como relative até atingir um limite de rolagem, depois "gruda" como fixed.

.cabecalho-tabela {
    position: sticky;
    top: 0; /* gruda no topo ao rolar */
    background: white;
}
💡 Use sticky para: cabeçalhos de tabela, títulos de seção, filtros que ficam visíveis ao rolar.

6. z-index — camadas

Controla a ordem de empilhamento. Funciona apenas em elementos com position diferente de static.

.modal    { position: fixed; z-index: 1000; }
.overlay  { position: fixed; z-index: 999; }
.dropdown { position: absolute; z-index: 50; }
.conteudo { position: relative; z-index: 1; }

.centrado {

    top: 50%;

}
