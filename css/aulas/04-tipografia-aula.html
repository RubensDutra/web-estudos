Aula 04 — Tipografia

Tipografia é o conjunto de propriedades CSS que controlam fontes, tamanhos, espaçamento e aparência do texto.

1. font-family

Define a família de fonte. Sempre indique uma fonte genérica como fallback.

font-family: Arial, Helvetica, sans-serif;
font-family: Georgia, "Times New Roman", serif;
font-family: "Courier New", Courier, monospace;
font-family: Verdana, Geneva, sans-serif;

Famílias genéricas

FamíliaCaracterísticasExemplos
serifCom serifa (tracinhos nas letras)Georgia, Times New Roman
sans-serifSem serifa — mais limpa, modernaArial, Roboto, Helvetica
monospaceLargura fixa — ideal para códigoCourier New, Source Code Pro
cursiveEstilo manuscritoPacifico, Dancing Script
fantasyDecorativaImpact
