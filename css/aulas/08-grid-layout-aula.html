Aula 08 — Grid Layout

O CSS Grid é um sistema de layout bidimensional — organiza elementos em linhas e colunas ao mesmo tempo. É ideal para estruturar páginas inteiras.

Grid vs Flexbox:
Flexbox → 1 dimensão (linha ou coluna). Use em componentes.
Grid → 2 dimensões (linhas e colunas). Use no layout da página.

1. Ativando o Grid

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr; /* 3 colunas iguais */
    gap: 10px;
}

grid-template-columns: repeat(4, 1fr);   /* mesmo que 1fr 1fr 1fr 1fr */

5. grid-template-areas — layout nomeado

.container {
    display: grid;
    grid-template-columns: 180px 1fr;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

6. Posicionamento de itens — grid-column e grid-row

.item {
    grid-column: 1 / 3;   /* da linha 1 até a linha 3 (ocupa 2 colunas) */
    grid-column: span 2;  /* ocupa 2 colunas a partir da posição atual */
    grid-row: span 2;     /* ocupa 2 linhas */
}

7. justify-items e align-items

/* no container — alinha TODOS os itens */
justify-items: start | center | end | stretch; /* eixo horizontal */
align-items:   start | center | end | stretch; /* eixo vertical */

/* no item individual */

8. minmax() e auto-fill / auto-fit

/* coluna com tamanho mínimo e máximo */
grid-template-columns: repeat(3, minmax(150px, 1fr));

/* grid responsivo automático — sem media queries! */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
/* auto-fill: mantém colunas vazias */
/* auto-fit: colapsa colunas vazias */
