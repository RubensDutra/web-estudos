Aula 05 — Box Model

O Box Model (modelo de caixa) é o conceito fundamental do CSS: todo elemento HTML é tratado como uma caixa retangular composta por 4 camadas.

1. As 4 Camadas do Box Model

┌─────────────────────────────────┐  ← MARGIN (espaço externo)
│  ┌───────────────────────────┐  │
│  │  BORDER (borda)           │  │
│  │  ┌─────────────────────┐  │  │
│  │  │  PADDING (interno)  │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │   CONTENT     │  │  │  │
│  │  │  │  (conteúdo)   │  │  │  │
│  │  │  └───────────────┘  │  │  │

│  └───────────────────────────┘  │

2. width e height

width: 300px;       /* largura do conteúdo */
height: 150px;      /* altura do conteúdo */
max-width: 100%;    /* largura máxima */
min-height: 200px;  /* altura mínima */
Por padrão, width e height definem o tamanho do conteúdo, sem incluir padding e border (isso muda com box-sizing).

3. padding

Espaço interno entre o conteúdo e a borda.

padding: 20px;                   /* todos os lados iguais */
padding: 10px 20px;              /* vertical | horizontal */
padding: 10px 20px 15px 5px;    /* top | right | bottom | left */

/* Lados individuais */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 15px;
padding-left: 5px;
Sem padding — texto colado na borda
Com padding: 40px — texto afastado da borda

4. margin

Espaço externo ao redor do elemento.

margin: 20px;                    /* todos os lados */
margin: 10px 20px;               /* vertical | horizontal */
margin: 10px 20px 15px 5px;     /* top | right | bottom | left */
margin: 0 auto;                  /* centraliza horizontalmente */

/* Lados individuais */
margin-top: 10px;
margin-right: auto;   /* empurra para a esquerda */
margin: 0 auto é o truque clássico para centralizar um elemento de bloco (quando ele tem width definido).
margin: 30px — observe o espaço ao redor desta caixa

5. border

border: 2px solid #333;       /* largura estilo cor */
border: 1px dashed red;
border: 3px dotted blue;

/* Lados individuais */
border-top: 2px solid #27ae60;
border-bottom: none;

/* Propriedades separadas */
border-width: 2px;
border-style: solid;   /* solid | dashed | dotted | double | none */
border-color: #333;

/* Bordas arredondadas */
border-radius: 8px;         /* todos os cantos */
border-radius: 50%;         /* círculo (para elemento quadrado) */
border-radius: 10px 0;      /* top-left/bottom-right | top-right/bottom-left */

6. box-sizing

Define como width e height são calculados.

content-box (padrão)

width define só o conteúdo. Padding e border são somados por fora.

.elemento {
    box-sizing: content-box;  /* padrão */
    width: 200px;
    padding: 20px;
    border: 5px solid red;
    /* tamanho total = 200 + 20+20 + 5+5 = 250px */
}

border-box (recomendado)

width inclui padding e border. O conteúdo encolhe para caber.

.elemento {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid green;
    /* tamanho total = 200px (sempre!) */
}
content-box: width 200px
real: 250px
border-box: width 200px
real: 200px
Boa prática: aplique box-sizing: border-box em tudo: 
*, *::before, *::after {
    box-sizing: border-box;
}

7. display

Controla como o elemento se comporta no fluxo da página.

display: block;         /* ocupa linha inteira */
display: inline;        /* flui junto com o texto, não aceita width/height */
display: inline-block;  /* flui como inline, mas aceita width/height */
display: none;          /* remove o elemento da tela */

block

div 1 — ocupa toda a largura
div 2 — vai para a próxima linha

inline

span 1 span 2 span 3 — fluem lado a lado
