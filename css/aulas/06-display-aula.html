Aula 06 — Display

A propriedade display define como um elemento se comporta no fluxo da página e como seus filhos são organizados. É a base de qualquer layout CSS.

1. Valores Principais

ValorComportamentoExemplos de elementos
blockOcupa toda a largura, vai para nova linhadiv, p, h1–h6, section
inlineFlui no texto, não aceita width/heightspan, a, strong, em
inline-blockFlui no texto, mas aceita width/heightimg (padrão), botões
noneRemove o elemento da tela e do fluxo— (aplicado via CSS)
flexAtiva Flexbox no container— (aplicado via CSS)
gridAtiva Grid no container— (aplicado via CSS)

2. display: block

Elementos block ocupam toda a largura disponível e sempre começam em uma nova linha.

div, p, h1, section {
    display: block; /* padrão desses elementos */
}
div 1 — bloco, ocupa a linha toda
div 2 — vai para a próxima linha automaticamente
div 3 — mesmo sem conteúdo, ocupa a largura

3. display: inline

Elementos inline fluem junto com o texto. Não aceitam width ou height.

span, a, strong {
    display: inline; /* padrão desses elementos */
}
span 1 span 2 span 3 — todos ficam na mesma linha
⚠️ width e height não funcionam em elementos inline. Use inline-block se precisar definir dimensões.

4. display: inline-block

Combina o melhor dos dois: flui horizontalmente como inline, mas aceita width e height.

.cartao {
    display: inline-block;
    width: 130px;
    padding: 15px;
    text-align: center;
}

6. display: grid (Grid Layout)

O Grid é um sistema de layout bidimensional — organiza elementos em linhas e colunas ao mesmo tempo. Ideal para layouts de páginas inteiras. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;  /* 3 colunas iguais */
    gap: 10px;
}

Flexbox vs Grid:
Use Flexbox para layouts em uma direção (menu, linha de cards, barra de botões).
Use Grid para layouts em duas direções (estrutura da página, galerias, tabelas visuais).

7. display: none vs visibility: hidden

display: none;          /* remove da tela E do fluxo (não ocupa espaço) */
visibility: hidden;     /* fica invisível MAS continua ocupando espaço */
