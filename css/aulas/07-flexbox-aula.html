Aula 07 — Flexbox

O Flexbox (Flexible Box Layout) organiza elementos em uma dimensão — linha ou coluna — distribuindo espaço e alinhando itens de forma inteligente. É ativado com display: flex no elemento pai (container).

Dois papéis no Flexbox:
• Container (pai) — recebe display: flex e controla o layout
• Itens (filhos) — são organizados pelo container

1. Ativando o Flexbox

.container {
    display: flex;   /* ativa o Flexbox — todos os filhos diretos viram flex-itens */
}

Sem Flexbox: cada <div> ocupa sua própria linha (block).

2. flex-direction — direção dos itens

Define o eixo principal: a direção em que os itens são dispostos.

flex-direction: row;             /* → esquerda para direita (padrão) */
flex-direction: row-reverse;     /* ← direita para esquerda */
flex-direction: column;          /* ↓ cima para baixo */
flex-direction: column-reverse;  /* ↑ baixo para cima */

row-reverse← horizontal invertido↕ vertical

3. justify-content — alinhamento no eixo principal

Distribui os itens ao longo do eixo principal (horizontal em row).

justify-content: flex-start;    /* agrupa no início (padrão) */
justify-content: flex-end;      /* agrupa no fim */
justify-content: center;        /* centraliza */
justify-content: space-between; /* espaço entre os itens */
justify-content: space-around;  /* espaço ao redor de cada item */
justify-content: space-evenly;  /* espaço igual entre todos */

💡 space-between vs space-around vs space-evenly:
• between: espaço entre os itens (bordas coladas nas extremidades)
• around: cada item tem metade do espaço nas laterais (extremidades menores)
• evenly: espaços iguais em todos os lados, incluindo extremidades

4. align-items — alinhamento no eixo cruzado

Alinha os itens no eixo cruzado (vertical em row).

align-items: stretch;     /* estica para preencher (padrão) */
align-items: flex-start;  /* alinha no topo */
align-items: flex-end;    /* alinha na base */
align-items: center;      /* centraliza verticalmente */
align-items: baseline;    /* alinha pela linha de base do texto */

5. gap — espaço entre os itens

Adiciona espaço entre os flex-itens, sem afetar as bordas externas do container.

gap: 16px;       /* mesmo espaço em todas as direções */
gap: 8px 24px;   /* gap-row gap-column (linha coluna) */
row-gap: 8px;    /* só entre linhas */
column-gap: 24px;/* só entre colunas */

6. flex — controle nos itens filhos

A propriedade flex é um atalho para três propriedades que controlam como cada item cresce, encolhe e qual é seu tamanho base. 

/* flex: grow  shrink  basis */
flex: 0    1      auto;   /* padrão */
flex: 1;                  /* cresce para preencher (flex: 1 1 0) */
flex: 2;                  /* cresce o dobro de flex:1 */
flex: none;               /* tamanho fixo, não cresce nem encolhe */

flex-grow — quanto o item cresce

flex-grow: 0;  /* não cresce (padrão) */
flex-grow: 1;  /* cresce igualmente com outros flex-grow:1 */
flex-grow: 2;  /* cresce o dobro de um flex-grow:1 */

flex-shrink — quanto o item encolhe

flex-shrink: 1;  /* encolhe se necessário (padrão) */

flex-basis — tamanho base antes de crescer/encolher

flex-basis: auto;   /* usa width/height do item (padrão) */
flex-basis: 150px;  /* tamanho inicial: 150px */
flex-basis: 0;      /* começa do zero — crescimento puramente proporcional */

Atalho flex — os mais usados

flex: 1;      /* equivale a: flex-grow:1 flex-shrink:1 flex-basis:0 */
flex: auto;   /* equivale a: flex-grow:1 flex-shrink:1 flex-basis:auto */
flex: none;   /* equivale a: flex-grow:0 flex-shrink:0 flex-basis:auto */
flex: 0 0 200px; /* tamanho fixo de 200px */

Leitura dos valores acima:
O item none tem 80px fixos. O espaço restante é dividido em 4 partes (1+2+1). O item flex: 1 pega 1 parte, o flex: 2 pega 2 partes.

7. flex-wrap — quebra de linha

flex-wrap: nowrap;   /* todos em uma linha (padrão) */
flex-wrap: wrap;     /* quebra para próxima linha se necessário */

Com wrap e flex: 1 1 150px, os cards se ajustam automaticamente ao espaço disponível:

8. Exemplo prático — barra de navegação

nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
    padding: 12px 24px;
    background: #2c3e50;
}
.nav-links {
    display: flex;
    gap: 20px;
    list-style: none;
}
