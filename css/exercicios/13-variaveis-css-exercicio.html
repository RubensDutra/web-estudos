Exercício 13 — Variáveis CSS

Exercício 1 — Sistema de cards com variáveis e escopo local ✓

Todos os cards compartilham a mesma estrutura. A cor do topo e do título muda pelo escopo local de --primaria.

Padrão

Usa --primaria do :root (#1abc9c)

Alerta

--primaria: #e74c3c (local)

Info

--primaria: #3498db (local)

Aviso

--primaria: #f39c12 (local)

:root { --primaria: #1abc9c; }

.card { border-top: 4px solid var(--primaria); }
.card h4 { color: var(--primaria); }

/* escopo local — só afeta este card e filhos */
.card.alerta { --primaria: #e74c3c; }
.card.info   { --primaria: #3498db; }
.card.aviso  { --primaria: #f39c12; }

Exercício 2 — Botões reutilizáveis com variáveis ✓

Uma única classe .btn-var com variáveis de cor locais. Variantes mudam só --btn-bg e --btn-hover.

.btn-var {
    --btn-bg:    var(--primaria);    /* verde padrão */
    --btn-hover: var(--secundaria);
    background: var(--btn-bg);
    transition: background 0.3s ease;
}
.btn-var:hover { background: var(--btn-hover); }

/* variantes: só redefine as variáveis locais */
.btn-var.perigo { --btn-bg: #e74c3c; --btn-hover: #c0392b; }
.btn-var.neutro { --btn-bg: #7f8c8d; --btn-hover: #636e72; }
