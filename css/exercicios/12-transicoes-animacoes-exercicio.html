Exercício 12 — Transições e Animações

Exercício 1 — Botão com transition ✓

O botão sobe 3 px e ganha sombra no :hover. No :active (clique) volta ao lugar. Tudo com transition.

.btn {
    background: #e67e22;
    transition: background 0.3s ease, transform 0.2s ease, box-shadow 0.3s ease;
}
.btn:hover {
    background: #d35400;
    transform: translateY(-3px);
    box-shadow: 0 6px 16px rgba(211,84,0,.35);
}
.btn:active {
    transform: translateY(0);
    box-shadow: none;
}

Exercício 2 — Spinner de carregamento com @keyframes ✓

Um spinner criado com bordas e animation + @keyframes. O texto pisca com outra animação.

Carregando...

@keyframes girar {
    from { transform: rotate(0deg); }
    to   { transform: rotate(360deg); }
}
.spinner {
    width: 56px; height: 56px;
    border: 6px solid #fce9d4;
    border-top-color: #e67e22;
    border-radius: 50%;
    animation: girar 0.9s linear infinite;
}

@keyframes piscar {
    0%, 100% { opacity: 1; }
    50%       { opacity: 0; }
}
.texto { animation: piscar 1.2s ease-in-out infinite; }
