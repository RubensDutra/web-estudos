Exercício 1 — Navbar com :hover e :not() ✓

Todos os links ficam roxos ao passar o mouse. Os separadores são adicionados em todos menos no último usando :not(:last-child).

.menu li a:hover { background: #8e44ad; }

/* separador em todos MENOS no último */
.menu li:not(:last-child) a { border-right: 1px solid #3d5166; }

Exercício 2 — Tabela com :nth-child, :first-child, :last-child e :hover ✓

Linhas ímpares em lilás claro, pares em branco. Primeira linha em negrito, última linha em cinza itálico. Hover muda a linha.

NºNomeNotaSituação
1Ana Lima9.5Aprovada
2Bruno Melo7.8Aprovado
3Carla Souza8.2Aprovada
4Diego Costa5.0Recuperação
5Eva Santos3.5Reprovada
 
.tabela tbody tr:nth-child(odd)  { background: #f5eef8; }
.tabela tbody tr:nth-child(even) { background: white; }
.tabela tbody tr:first-child td  { font-weight: bold; }
.tabela tbody tr:last-child td   { color: #888; font-style: italic; }
.tabela tbody tr:hover           { background: #e8daef; }
