Exercício 1 — Grid responsivo com media queries ✓

O grid abaixo começa com 1 coluna (mobile), passa para 2 em ≥ 600 px e para 3 em ≥ 900 px. Redimensione a janela para ver o efeito.

/* Mobile first */
.ex1-grid { display: grid; grid-template-columns: 1fr; gap: 12px; }

@media (min-width: 600px) {
    .ex1-grid { grid-template-columns: 1fr 1fr; }
}
@media (min-width: 900px) {
    .ex1-grid { grid-template-columns: 1fr 1fr 1fr; }
}

Exercício 2 — Navbar responsiva ✓

Em telas ≤ 480 px os links ficam abaixo do nome da marca (flex-direction: column). Acima disso ficam na mesma linha.
