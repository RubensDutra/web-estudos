Exercício 2 — none vs visibility: hidden

Tarefa: Observe a diferença entre as duas formas de esconder elementos.
  1. Adicione visibility: hidden à caixa 2 (ela deve sumir mas manter seu espaço).
  2. Adicione display: none à caixa 3 (ela deve sumir e o espaço desaparece).
💡 Ative os comentários em .ex2-caixa.invisivel e .ex2-caixa.removida

Exercício 3 — Flexbox: barra de navegação

Tarefa: Monte a barra de navegação usando Flexbox.
  • O .ex3-nav deve ser um flex container com justify-content: space-between.
  • Os links (.ex3-links) também devem ser flex com gap: 20px.
  • Use align-items: center no nav para alinhar logo e links verticalmente.
💡 Ative os comentários nas classes .ex3-nav, .ex3-links

Exercício 4 — Flexbox: galeria de cards

Tarefa: Crie uma galeria responsiva com Flexbox.
  • Aplique display: flex; flex-wrap: wrap; gap: 15px; no container.
  • Cada card deve ter flex: 1 1 200px — cresce, encolhe, base de 200px.
