Exercício 3 — box-sizing

Crie dois elementos com exatamente as mesmas propriedades, mas com box-sizing diferente:
  • Ambos: width 250px, padding 25px, border 5px solid, margin 10px 0
  • #content-box: box-sizing content-box, background #fdf2f2, border-color #e74c3c
  • #border-box: box-sizing border-box, background #eafaf1, border-color #27ae60
Depois, responda nos comentários: qual deles tem 250px de largura total? Por quê?
content-box: width 250px + padding + border = ???px total
border-box: width 250px (inclui tudo) = 250px total

Exercício 5 — Layout com Box Model

Monte o layout de um card de perfil estilizando apenas no CSS:
  • #perfil: width 280px, margin 0 auto, border 1px solid #ddd, border-radius 12px, overflow hidden, background white
  • #perfil .avatar: display block, width 80px, height 80px, border-radius 50%, background #3498db, margin 20px auto 10px, line-height 80px, text-align center, color white, font-size 28px, font-weight bold
  • #perfil .nome: text-align center, font-size 20px, font-weight bold, color #2c3e50, margin 0 0 5px
  • #perfil .cargo: text-align center, color #888, font-size 14px, margin 0 0 20px
  • #perfil .stats: display flex (pesquise sobre flexbox!), border-top 1px solid #eee
  • #perfil .stat: flex 1, text-align center, padding 15px 0
  • #perfil .stat strong: display block, font-size 18px, color #2c3e50
  • #perfil .stat span: font-size 12px, color #888
