Disciplinas do Curso

O curso abrange disciplinas de programação, banco de dados, web e inteligência artificial, unindo teoria e prática para preparar o aluno para o mercado.

  1. Banco de Dados
  2. Java
  3. Web I
  4. Aprendizado de Máquinas

Conteúdos por Disciplina

Os conteúdos das disciplinas se complementam, integrando banco de dados, programação, web e IA na construção de sistemas completos.

  • Banco de Dados
    • Modelagem Entidade-Relacionamento
    • SQL básico
    • Normalização
  • Java
    • Orientação a Objetos
    • Estruturas de controle
    • Coleções e arrays
  • Web I
    • HTML estrutural
    • CSS básico
    • Formulários e inputs

Ementas

As ementas descrevem os conteúdos programáticos de cada disciplina, servindo de guia para professores e alunos ao longo do semestre.

Banco de Dados
Aborda modelagem de dados, SQL, normalização e integridade referencial aplicados a sistemas de informação.
Aprendizado de Máquinas
Estuda algoritmos de aprendizado supervisionado e não supervisionado, pré-processamento de dados e aplicações práticas com Python.
