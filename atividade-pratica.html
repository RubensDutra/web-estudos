O curso em Análise e Desenvolvimento de Sistemas, é um curso completo e nos dá uma visão de como funciona o mundo da tecnologia e suas ferramentas de trabalho.

Disciplinas do Curso

O curso de Análise e Desenvolvimento de Sistemas contempla disciplinas que cobrem desde a programação orientada a objetos até o desenvolvimento de sistemas web modernos, banco de dados e inteligência artificial. Cada disciplina foi pensada para preparar o aluno para o mercado de trabalho, combinando teoria e prática em projetos reais ao longo do semestre.

  1. Banco de Dados
  2. Java
  3. Web I
  4. Aprendizado de Máquinas

Conteúdos por Disciplina

Cada disciplina abrange um conjunto de conteúdos complementares entre si. O aluno é incentivado a conectar os conhecimentos adquiridos em cada área, percebendo como banco de dados, programação, web e inteligência artificial se integram na construção de sistemas completos e escaláveis. A prática constante por meio de exercícios e projetos é fundamental para a fixação dos conceitos apresentados em sala de aula.

  • Banco de Dados
    • Modelagem Entidade-Relacionamento
    • SQL básico
    • Normalização
  • Java
    • Orientação a Objetos
    • Estruturas de controle
    • Coleções e arrays
  • Web I
    • HTML estrutural
    • CSS básico
    • Formulários e inputs

Ementas

As ementas oficiais descrevem os objetivos e conteúdos programáticos de cada disciplina conforme aprovado pelo colegiado do curso. Elas servem como guia tanto para o professor organizar as aulas quanto para o aluno entender o que será exigido ao longo do semestre. Conhecer a ementa ajuda no planejamento dos estudos e na antecipação dos temas que exigem maior dedicação e aprofundamento.

Banco de Dados
Estuda os conceitos fundamentais de banco de dados relacionais, modelagem de dados, linguagem SQL, normalização e integridade referencial com foco em sistemas de informação reais.
Aprendizado de Máquinas
Aborda os principais algoritmos de aprendizado supervisionado e não supervisionado, técnicas de pré-processamento de dados, avaliação de modelos e aplicações práticas com Python.
