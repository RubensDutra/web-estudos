Formatação de Texto

Texto em negrito — use para informações importantes.

Texto em itálico — use para ênfase ou termos técnicos.

Texto sublinhado — evite, pois parece link.

Texto destacado — ótimo para chamar atenção.

Texto pequeno — para rodapés e notas.

Texto riscado — indica algo removido ou desatualizado.
