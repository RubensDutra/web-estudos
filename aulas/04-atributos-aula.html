Atributos Booleanos

Atributos booleanos funcionam só com a presença do nome, sem precisar de valor: 


<input disabled />       ← campo desabilitado
<input checked />        ← checkbox marcado
<input required />       ← campo obrigatório
<input readonly />       ← somente leitura
<video autoplay />       ← vídeo toca automaticamente
<p hidden>...</p>       ← elemento invisível

Resumo


Atributos globais (funcionam em qualquer tag):
  id="unico"              → identificador único
  class="nome"            → classe reutilizável
  style="css: valor"      → estilo inline
  title="dica"            → tooltip ao passar o mouse
  lang="pt-BR"            → idioma do conteúdo
  hidden                  → esconde o elemento

Atributos específicos (exemplos):
  <a href="" target="" rel="">
  <img src="" alt="" width="" height="" loading="">

Atributos booleanos (só a presença já ativa):
  disabled, checked, required, readonly, hidden, autoplay

Atributos personalizados:
  data-qualquercoisa="valor"
