LINKS:
  <a href="url">texto</a>                  → link básico
  <a href="url" target="_blank"
     rel="noopener noreferrer">            → nova aba (seguro)
  <a href="#id">                            → âncora na página
  <a href="mailto:email@x.com">            → e-mail
  <a href="tel:+55...">                    → telefone
  <a href="arquivo.pdf" download>          → download

IMAGENS:
  <img src="url" alt="descrição" />        → obrigatório
  <img ... width="300" height="150" />     → dimensões
  <img ... loading="lazy" />               → lazy load
  <img ... alt="" />                       → decorativa
  <a href="url"><img src="..." alt=""/></a> → imagem clicável
