Fundamentos do HTML

HTML significa HyperText Markup Language. É a base de toda página web — define a estrutura e o conteúdo.

Como o navegador lê um arquivo HTML?

O navegador lê o arquivo de cima para baixo, interpretando cada tag e exibindo o conteúdo na tela para o usuário.

Regras importantes

1. Todo arquivo HTML começa com <!DOCTYPE html> — isso avisa ao navegador que é um documento HTML5 moderno.

2. As tags geralmente vêm em pares: abertura <tag> e fechamento </tag>. Algumas são auto-fechadas, como <meta /> e <br />.

3. A indentação (recuo) não é obrigatória, mas é essencial para deixar o código organizado e legível.

Resumo da estrutura


<!DOCTYPE html>          ← declara HTML5
<html lang="pt-BR">     ← elemento raiz
  <head>               ← metadados (invisíveis)
    <meta charset="UTF-8" />
    <title>Título</title>
  </head>
  <body>               ← conteúdo visível
    <h1>Olá, mundo!</h1>
  </body>
</html>
