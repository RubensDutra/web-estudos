Exercício 3 — Seletor de Atributo

Use seletores de atributo para estilizar os campos abaixo:
  • input[type="text"]: borda verde 2px sólida, padding 6px
  • input[type="password"]: borda vermelha 2px sólida, padding 6px
  • input[type="submit"]: background azul, cor branca, padding 8px 16px, sem borda, cursor pointer
  • a[target="_blank"]: cor laranja e adicione ::after { content: " ↗"; }

Exercício 4 — Pseudo-classes

Adicione estilos usando pseudo-classes:
  • li:hover: fundo verde claro ao passar o mouse
  • li:first-child: negrito e cor verde
  • li:nth-child(3): cor azul
  • li:last-child: itálico e cor cinza
  • input:focus: outline azul de 3px
  • HTML (primeiro filho — negrito verde)
  • CSS
  • JavaScript (terceiro filho — azul)
  • Python
  • Java (último filho — itálico cinza)

Exercício 5 — Pseudo-elementos

  • .aviso::before: content: "⚠️ ATENÇÃO: ", cor laranja
  • .concluido::after: content: " ✓", cor verde, negrito

Este parágrafo tem a classe texto-grande. A primeira letra deve ficar enorme e vermelha.
