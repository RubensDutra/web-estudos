# 🌐 Estudos e Prática em Web

Repositório dedicado ao aprendizado e desenvolvimento de projetos em **Desenvolvimento Web**. Aqui você encontrará materiais de aula, exercícios práticos e projetos desenvolvidos durante o curso.

---

## 📚 Sobre este Repositório

Este é um espaço de aprendizagem contínuo focado em:
- **HTML5** — Estrutura semântica e acessibilidade
- **CSS3** — Estilização, layout e responsividade
- **JavaScript** — Lógica, DOM manipulation e ES6+
- **Projetos práticos** — Aplicações reais e funcionais

---

## 🎯 Objetivo

- Consolidar conhecimentos em desenvolvimento web
- Praticar com exercícios progressivos
- Desenvolver projetos reais e funcionais
- Acompanhar evolução do aprendizado através do Git

---

## 🚀 Como Usar

1. **Clone o repositório** (se quiser uma cópia local):
   ```bash
   git clone https://github.com/RubensDutra/web-estudos.git
   cd web-estudos
   ```

2. **Navegue pelos conteúdos** — cada pasta contém materiais organizados por tema

3. **Estude e pratique** — abra os arquivos em seu editor favorito

4. **Execute os projetos** — abra os arquivos `.html` em um navegador

## 📝 Como Contribuir com Você Mesmo

Se está using este repositório como referência:

1. Faça um **fork** do repositório
2. Crie uma **branch** com seu nome: `git checkout -b seu-nome`
3. Faça **commits** descritivos em português
4. Faça um **push** e abra um pull request
